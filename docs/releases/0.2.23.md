# Whispera (K) 0.2.23

## Inicio automático corregido

Solucionamos el problema que impedía que Whispera se iniciara con Windows aunque la opción estuviera activada. La entrada de inicio podía seguir apuntando a una instalación anterior que ya no existía.

- Whispera comprueba la ruta real que utiliza Windows y corrige las entradas antiguas al abrirse.
- La opción de inicio automático verifica que Windows haya guardado el cambio correctamente.
- Si desactivaste el inicio automático, tu elección se conserva.

## Grabación hacia atrás más clara

- El encabezado muestra una acción Configurar y una flecha para abrir sus opciones.
- El botón Configurar y activar te guía para crear la carpeta y elegir un atajo.
- Cuando esos pasos están completos, aparece Activar grabación. La captura en segundo plano empieza únicamente al pulsarlo.
- Podés detenerla desde Desactivar grabación. Se mantienen los colores y las formas de la interfaz.
