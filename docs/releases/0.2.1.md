# Whispera (K) 0.2.1

Corrige condiciones que podían dejar el dictado copiado sin pegarlo en el campo original:

- El destino se captura antes de inicializar el micrófono y la transcripción incremental.
- Los campos de ventanas con varios procesos, como Electron/WebView, se validan por su pertenencia a la ventana original; el proceso del campo puede ser distinto del proceso de la ventana.
- Se espera a que se suelten Alt, Control, Shift y Windows antes de enviar Ctrl+V. No se liberan teclas físicas por la fuerza.
- La carpeta de dictado se oculta antes de recuperar el foco del campo. Se comprueba la activación del campo durante un intervalo acotado antes del pegado.
- Se envía Ctrl+V una sola vez. Las comprobaciones previas pueden esperar, pero el pegado no se repite para evitar texto duplicado.
- Los errores de pegado se registran en el historial de eventos; el texto sigue disponible en el portapapeles y el historial de transcripciones.

Validación: compilación TypeScript/Vite y pruebas Rust, incluida una prueba con ventanas nativas para validar campos pertenecientes a otra ventana y controles destruidos. La herramienta de control de Windows rechazó la identificación de la ventana de Codex, de modo que no se completó una prueba de pegado de punta a punta dentro de Codex. No se afirma que se hayan cubierto todas las aplicaciones receptoras.

Conserva el identificador de datos y credenciales de 0.2.0. Windows puede bloquear la inyección de teclas entre aplicaciones con distintos niveles de permisos; en ese caso se conserva el texto copiado.
