# Contributing / Colaborar

Use a branch and pull request. Describe behavior changes, include tests, and preserve original recordings.
Use public audio fixtures or explicitly consented recordings; never attach private audio, keys, database
files or raw memory dumps. Run the source scanner, TypeScript build and Rust tests before submitting.
No provider fallback or automatic cloud upload without user consent. UI should respect reduced motion.

Usá una rama y un pull request, describí los cambios y agregá pruebas. No adjuntes audios privados,
claves, bases de datos ni volcados de memoria. Conservá los originales y el consentimiento para envíos.
