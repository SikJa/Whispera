# Whispera (K) 0.2.5

Reduce la espera al activar capturas y selección de video:

- Prepara las ventanas de selección ocultas al iniciar, en lugar de crearlas al primer atajo. Se reutilizan; no hay capturas continuas ni consultas periódicas adicionales.
- Congela los píxeles sin comprimir la pantalla completa a PNG. La vista previa usa un BMP en memoria y solo el recorte elegido se comprime a PNG sin pérdida para editar y copiar.
- Lee la apariencia y la vista previa en paralelo.
- Elimina el oscurecimiento inicial de toda la pantalla al activar la selección.
- Cancela la preparación de una vista si se cerró o reemplazó, evitando mostrar una selección vieja.

Se mantienen los atajos, Escape, el borde configurable, las herramientas de edición y el formato PNG final. Las imágenes congeladas se liberan al cancelar o finalizar la selección. Los monitores nuevos se preparan al seleccionar si no estaban presentes al iniciar.

Validación: 75 pruebas Rust aprobadas, incluyendo orden de píxeles, recorte exacto, coordenadas negativas y límites. Compilación de interfaz e instalador y medición local de preparación de imágenes.

Medición local en 1536×864 (5 capturas): congelado nativo 27–47 ms; preparación de vista previa PNG anterior 4,6–4,8 ms frente a BMP 0,62–0,67 ms. Son tiempos de preparación, no una medición completa de respuesta al atajo. El registro local incluye ahora el tiempo hasta mostrar el selector para diagnosticar demoras reales.

Dictado: reutiliza la conexión HTTP entre solicitudes, elimina la pausa fija de 100 ms después de copiar y evita escanear otra vez todo el campo de accesibilidad en cada comprobación de pegado. Mantiene la validación del destino, del portapapeles y un único Ctrl+V. Registra por separado el tiempo hasta recibir el texto y el de copiar/pegar. No cambia el modelo ni recorta palabras para acelerar.

Impr Pant: elimina el descarte silencioso cuando el editor anterior seguía abierto; usa el mismo recorrido de captura que el botón y los demás atajos.

También pasaron 11 suites de interfaz con IPC simulado y una prueba HTTP local que verifica reutilización de la conexión y aislamiento de credenciales entre solicitudes. No se enviaron grabaciones personales para probar el servicio.
