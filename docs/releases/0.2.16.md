# Whispera (K) 0.2.16

Al seleccionar un tema en Configuración → Sonidos se reproduce una muestra de inicio y fin de hasta dos segundos. La elección se guarda únicamente al pulsar Guardar.

Cambiar de tema o salir de Sonidos detiene la muestra anterior. Los botones para escuchar inicio y fin por separado también comparten ese control para evitar sonidos superpuestos.

El botón de descarga del README obtiene directamente el instalador de la última versión estable para Windows. La publicación incluye ese enlace fijo, además del instalador con su número de versión, firmas y comprobaciones de integridad.

Validación: compilación de escritorio y prueba de reproducción con audio real silenciado, guardado explícito, interrupción de muestras y salida de la sección. Las preferencias existentes se conservaron al instalar la actualización local.
