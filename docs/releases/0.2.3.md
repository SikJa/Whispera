# Whispera (K) 0.2.3

Corrige configuraciones que parecían desaparecer al cerrar Whispera, reiniciar Windows o abrirla desde Codex. El lanzamiento desde una aplicación empaquetada podía redirigir AppData a una carpeta distinta y hacer que la app leyera otro perfil.

La base de datos ahora tiene una ubicación única por usuario: `%USERPROFILE%\.whispera\desktop\whispera.sqlite`. Al actualizar se conserva el perfil que estabas usando mediante una copia de seguridad de SQLite, incluidas las modificaciones confirmadas que todavía estén en el archivo WAL. La importación se realiza una sola vez; los siguientes inicios no reemplazan las preferencias actuales por un perfil anterior. Los archivos de audio, imagen y video existentes se conservan.

Si la base anterior está dañada o la migración falla, se informa el error en vez de arrancar silenciosamente con valores predeterminados. El guardado sigue siendo inmediato al presionar Guardar.

Validación: pruebas de reapertura de atajos y preferencias, migración con WAL activo, inicio desde otro perfil y rechazo de una base dañada, además de las pruebas Rust existentes y la compilación del instalador. En la instalación local se comprueba que la configuración sea idéntica antes y después de dos inicios. La integración de pegado dentro de Codex sigue dependiendo de su campo editable y no se certifica con estas pruebas de persistencia.

Referencia de Windows: [redirección de carpetas de aplicaciones empaquetadas](https://learn.microsoft.com/en-us/windows/win32/api/shlobj_core/ne-shlobj_core-known_folder_flag).
