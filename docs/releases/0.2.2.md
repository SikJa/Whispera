# Whispera (K) 0.2.2

Recupera el último campo editable usado en la ventana original al terminar el dictado. Cambiar a esa ventana puede dejar el foco en su documento, un botón o un panel; ya no es necesario volver a hacer clic en el mismo campo cuando Windows expone ese campo mediante accesibilidad.

La app recuerda hasta 16 ventanas y retiene como máximo 16 destinos de dictado. Un hilo dedicado consulta el campo enfocado cada 250 ms mientras otra aplicación está activa. No lee ni guarda su texto, y los objetos de accesibilidad permanecen en el mismo hilo COM. Se comprueba que el control pertenece a la ventana original antes de recordarlo y de devolverle el foco. Si el campo desaparece o Windows impide recuperarlo, el texto queda copiado y guardado en el historial.

También incluye las correcciones de 0.2.1: captura temprana del destino, espera a que se suelten los modificadores del atajo, compatibilidad con controles en otro proceso, cierre del indicador antes del pegado y registro de fallos. Se comprueba nuevamente el portapapeles antes de enviar Ctrl+V, que se envía una sola vez para evitar duplicados.

Validación: pruebas Rust, incluidas comprobaciones con ventanas nativas y el proveedor de accesibilidad de un campo de texto de Windows, y compilación de la interfaz y el instalador. El control automatizado de Codex falló al identificar su ventana: no se completó una prueba de punta a punta dentro de Codex. La recuperación depende de que la aplicación exponga un control editable compatible; no se intenta adivinar un campo que nunca se usó ni el lugar al que mira el usuario.

Mantiene el identificador de datos y credenciales de 0.2.0. No requiere volver a configurar Groq.
