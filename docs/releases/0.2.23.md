# Whispera 0.2.23

## Espanol

Integra las novedades de Whispera-K hasta 0.2.22 con las correcciones locales de SikJa/Whispera. Conserva el logo Cristal.

- Replay opcional con recorte del tramo guardado y transcripcion cuando corresponde. Permanece apagado hasta que lo actives.
- Capturas simultaneas durante video, seleccion ajustable y aislamiento de eventos entre ventanas.
- Preferencias con guardado automatico, acceso a Aplicacion e inicio con Windows.
- Perfil unico fuera de AppData virtualizado, con migracion SQLite que conserva los cambios pendientes del WAL.
- Se mantienen las defensas contra sobrescritura del diccionario, interrupciones de audio y cierres involuntarios.
- Copiar y arrastrar videos usa archivos compartibles fuera del AppData privado, incluido el video recortado.
- Actualizaciones verificadas con una firma propia de SikJa/Whispera. La clave privada no forma parte del repositorio.

El historial, los atajos y la configuracion se conservan. Groq sigue usando tu credencial de Windows. La firma del actualizador no equivale a un certificado Authenticode de Windows: SmartScreen puede mostrar un aviso.

## English

Integrates Whispera-K through 0.2.22 with SikJa/Whispera's local fixes while keeping the Cristal logo.

- Optional Replay with trimming and transcription where applicable; disabled until enabled.
- Concurrent screenshots during video, adjustable selection, and isolated window events.
- Autosaved preferences and a Windows startup section.
- A single profile outside virtualized AppData, migrated using SQLite backup including committed WAL pages.
- Dictionary conflict protection, resilient audio recording, and lifecycle safeguards remain enabled.
- Copying and dragging videos, including trimmed clips, exports shareable files outside private AppData.
- Updates verified with SikJa/Whispera's own signature. The private key is not stored in the repository.

Settings, shortcuts and history are preserved. Groq continues using Windows Credential Manager. Updater signatures are not Windows Authenticode certificates; SmartScreen may still warn.

## Verification boundaries

Local validation: 124 native tests passed; 14 opt-in tests were not run. All 29 silent headless UI suites passed. The Windows startup provider passed enable/read/repair/disable checks in isolated registry keys. The signing test accepted the signed fixture and rejected altered bytes.

Automated UI checks use mocked native IPC, run headless and mute audio. They do not certify physical microphone behavior, receiver-specific paste/drop, multiple monitors, reboot behavior or long-running stability. Release checks include native unit tests, profile migration and signature/tampering tests. See the release handoff for actual results.
