# Whispera (K) 0.2.4

Agrega la opción «Impr Pant para Whispera» en Capturas y video. Mientras Whispera está abierto y la opción está activada:

- Impr Pant abre la selección de captura de Whispera.
- Se interceptan las capturas de Windows con Impr Pant y Win + Shift + S.
- Ctrl + Alt + Shift + F12 abre la captura de Windows.

La tecla física permanece intacta: no se modifica Scancode Map ni se instalan programas de remapeo. La opción se guarda inmediatamente y se puede desactivar desde Configuración. Viene desactivada por defecto para las demás instalaciones. Cuando Whispera se cierra, Windows recupera sus atajos habituales.

El teclado se procesa en un hilo de mensajes de Windows, sin consultas periódicas ni guardar lo que se escribe. Un segundo hilo ejecuta las capturas fuera del callback del teclado. La cola es limitada y las pulsaciones repetidas se suprimen hasta soltar la tecla. Las otras letras y combinaciones siguen pasando normalmente; durante la configuración de atajos se libera la captura de teclas. Las entradas sintéticas de herramientas de accesibilidad pasan sin bloquearse.

Validación: 73 pruebas Rust, incluida la instalación y retirada de un hook nativo que deja pasar todas las teclas, y comprobaciones de las combinaciones que se interceptan. Compilación de la interfaz y del instalador. No se certifica una prueba física de Impr Pant hasta reiniciar Windows si una configuración previa de Scancode Map había bloqueado la tecla.
