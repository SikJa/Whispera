# Whispera 0.2.33 - Windows

## Español

- Selector de pantalla para grabar un monitor completo.
- Orientación horizontal o vertical de las herramientas de captura.
- Tamaño estable al contraer y expandir las barras, sin realimentación entre el contenido y la ventana.
- Posicionamiento calculado con el tamaño real de las herramientas y acción para restablecer su ubicación.
- Paneles de herramientas adaptados a la orientación horizontal.
- Mayor tiempo de preparación para videos largos: mínimo de 15 minutos, ajustado a la duración y limitado a 2 horas.
- Si falla la preparación del video, se conservan los originales y se intenta recuperar el micrófono en Audios pendientes. Los videos pendientes aparecen en Capturas y video.
- Instalador y manifiesto de actualización firmados para el actualizador de Whispera. Esto no implica firma Authenticode de Windows.

La opción **Copiar al soltar la selección** sigue siendo opcional: desactivala para abrir las herramientas después de cada captura. Esta versión conserva las preferencias de cada usuario.

Validación del código previo a la publicación: 181 pruebas nativas aprobadas, 32 omitidas y 39 suites de interfaz headless aprobadas. Las suites de interfaz simulan la integración nativa; no certifican todos los equipos, monitores ni permisos de Windows.

## English

- Select a detected display to record its full screen.
- Switch capture tools between horizontal and vertical layouts.
- Stable collapse and expansion without content/window resize feedback.
- Position toolbars using their measured dimensions; reset their placement when needed.
- Position tool panels below or above horizontal toolbars.
- Longer video finalization budget: at least 15 minutes, adjusted to recording duration, capped at 2 hours.
- Failed finalization preserves source files and attempts to recover microphone audio into pending recordings. Pending videos remain discoverable in capture settings.
- Signed installer update artifacts and updater manifest. This does not imply Windows Authenticode signing.

Disable **Copy on selection release** to open the editor after taking a screenshot. Existing user preferences remain unchanged.

Pre-publication source validation: 181 native tests passed, 32 skipped, and 39 headless UI suites passed. UI suites mock native integration; actual behavior still depends on the user's hardware and Windows environment.
