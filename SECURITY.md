# Security / Seguridad

Do not report credentials or private recordings in public issues. Use GitHub private vulnerability reporting
when enabled, or contact the repository owner privately before sharing sensitive details.
Until a secure contact is established, describe only the issue category, not secret values.
Supported release line: 0.1.x beta, Windows x64. No security SLA is offered.

No publiques claves ni grabaciones en issues. Contactá al propietario en privado o usá el reporte privado
de GitHub cuando esté habilitado. Compartí inicialmente solo la categoría del problema, nunca secretos.
