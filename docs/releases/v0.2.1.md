# Whispera 0.2.1

## Español

- El diccionario se actualiza al abrir su sección o volver a la ventana. Una pantalla desactualizada ya no puede reemplazar reglas guardadas más recientemente.
- El guardado conserva la versión anterior del diccionario dentro de la base local.
- Nueva opción **Configuración > General > Iniciar Whispera con Windows**, con lectura y confirmación del estado real de Windows.
- Al iniciar automáticamente, Whispera espera hasta 90 segundos si una carpeta de datos redirigida todavía no está disponible.
- Corregida la selección de **Impr Pant**, incluso en teclados que sólo envían el evento al soltar la tecla.
- Al copiar videos, se eliminan formatos viejos del portapapeles que podían interferir con el pegado. Los archivos se comprueban antes de reemplazar el contenido copiado.
- Diagnóstico identifica el perfil activo y la cantidad de reglas al arrancar, sin registrar las palabras del diccionario.

**Instalación:** descargá `Whispera_0.2.1_x64-setup.exe`. El instalador conserva el mismo identificador de aplicación y no incluye claves API, diccionarios ni grabaciones personales. Para transcribir necesitás tu propia clave de Groq.

**Verificación:** pruebas Rust de persistencia y conflictos de diccionario; 12 suites de interfaz headless y silenciosas. La prueba de portapapeles nativo usa una estación privada de Windows. La validación del inicio automático tras un reinicio completo y la instalación en una PC limpia siguen pendientes. El instalador no tiene firma de código; las actualizaciones automáticas no están habilitadas.

## English

- Dictionary rules refresh when opening the section or returning to the window. An outdated screen can no longer overwrite newer saved rules.
- Each successful dictionary save retains the previous version in the local database.
- New **Settings > General > Start Whispera with Windows** switch, with Windows state readback after changes.
- Automatic startup waits up to 90 seconds when a redirected data directory is temporarily unavailable.
- Fixed **Print Screen** shortcut capture, including keyboards that only send a key-release event.
- Copying videos clears stale clipboard formats that could interfere with pasting. File availability is checked before replacing the clipboard contents.
- Startup diagnostics identify the active profile and rule count without logging dictionary words.

**Installation:** download `Whispera_0.2.1_x64-setup.exe`. The application identifier remains unchanged. No personal API keys, dictionaries or recordings are bundled. Transcription requires your own Groq API key.

**Validation:** Rust dictionary persistence and conflict tests; 12 silent headless UI suites. The native clipboard regression test uses a private Windows window station. Full reboot autostart validation and installation on a clean PC remain pending. The installer is unsigned; automatic updates remain disabled.
