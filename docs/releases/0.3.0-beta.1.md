# Whispera 0.3.0-beta.1 - macOS Preview

## Espanol

Primera beta nativa para **macOS 13 o posterior**, con DMG para
[Apple Silicon](https://github.com/SikJa/Whispera/releases/download/v0.3.0-beta.1/Whispera_0.3.0-beta.1_aarch64.dmg)
e [Intel](https://github.com/SikJa/Whispera/releases/download/v0.3.0-beta.1/Whispera_0.3.0-beta.1_x86_64.dmg).

- Conserva el logo Cristal, la interfaz, Groq, el diccionario, la transcripcion
  anticipada por fragmentos, el historial y la recuperacion de audio.
- Agrega grabadora flotante AppKit, atajos Cmd, barra de menus, inicio de sesion
  opcional, clave de Groq en Keychain y controles de permisos.
- Integra captura y video con ScreenCaptureKit, microfono/audio del sistema,
  FFmpeg incluido, recorte, Replay opcional, editor, fondos y composicion.
- Adapta portapapeles, arrastre nativo y restauracion del destino con Accesibilidad.
- Refuerza cierre de captura, buffers de microfono, escritura al codificador,
  comprobaciones de pegado y limpieza de callbacks de ventanas.
- Usa actualizaciones verificadas con la firma de SikJa en un canal Mac separado.
  **Windows 0.2.27 sigue siendo la version estable y no recibe esta beta.**

Compilaciones y arranque comprobados en runners macOS para ambas arquitecturas:
139 tests nativos por arquitectura, interfaz headless WebKit, recursos,
arquitecturas y firma del actualizador. La regresion Windows paso 146 tests
nativos y 30 suites de interfaz headless. Las pruebas de interfaz usan IPC
simulado; los tests omitidos no se cuentan como aprobados.

**No se probo en una Mac fisica.** Los DMG tienen firma ad-hoc y no estan
notarizados por Apple. Microfono, permisos, monitores, foco/pegado y arrastre en
aplicaciones reales requieren validacion de usuarios de Mac.
[Guia de instalacion y limites](../MACOS.md).

## English

First native preview for **macOS 13+**, with separate Apple Silicon and Intel
DMGs. It preserves Cristal and the shared Groq application, adding native
AppKit windows, Cmd shortcuts, Keychain, permission controls, Accessibility
paste, NSPasteboard/drag and ScreenCaptureKit screenshot/video/audio capture.
It includes the shared editor, clipboard history, recovery, incremental
transcription, trimming and optional hardware-encoded Replay.

Both architecture builds passed 139 native tests, headless WebKit fixtures,
bundle/resource checks, updater-signature verification and a brief app startup
check. Windows passed 146 native tests and 30 silent headless UI suites.
UI fixtures mock native IPC; ignored tests are not counted as passes.

**No physical Mac was available for device testing.** Builds are ad-hoc signed,
not Apple-notarized. Real recording, permission approval, displays, destination
paste and external dragging remain unverified. The Mac preview update feed is
separate; stable Windows stays on 0.2.27.
