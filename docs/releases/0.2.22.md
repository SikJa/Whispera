# Whispera (K) 0.2.22

## Novedades

- Replay opcional de la pantalla principal: duración configurable, carpeta obligatoria, archivos con fecha/hora y audio opcional.
- Al guardar una repetición, un editor permite seleccionar el tramo que se conserva. Guardar o Ctrl+C produce el video y, si corresponde por el audio elegido, su transcripción.
- Sección Aplicación con inicio automático de Windows; Diccionario personal dentro de Tu espacio desplegable.
- Importación de archivos más compacta y notas de actualización breves, con el progreso ubicado junto al mensaje.

## Correcciones

- El silencio digital exacto ya no se envía para producir transcripciones inventadas; la voz baja no se descarta por un umbral de volumen.
- Las grabadoras evitan repintados cuando el estado recibido no cambió. El diccionario reutiliza el patrón Unicode de límites de palabras.
- Replay libera su estado ocupado cuando una tarea se descarta y revalida la habilitación al iniciar. Los cortes fraccionarios conservan los cuadros del intervalo solicitado.
- Ctrl+C guarda el recorte incluso después de usar un deslizador.
- Volver desde importar o ver detalles recupera la ventana principal.
- Si falla iniciar una captura, se mantienen selección y error para reintentar.
- Capturas y portapapeles esperan la lectura de preferencias antes de permitir editarlas; un error permite reintentar sin sobrescribirlas con valores predeterminados.
- Los atajos reconocen teclas virtuales inequívocas cuando falta el código físico.
- El estante abre el actualizador de Whispera y enlaza las novedades de este repositorio. Los fallos de guardado se muestran y no aparentan éxito.

## Validación y límites

Se ejecutaron 103 pruebas nativas ordinarias, 10 optativas por separado, 28 suites de interfaz y casos adicionales de opciones, estante y composición. Las pruebas con comunicación nativa simulada se distinguen de los recorridos reales de Windows. Se comprobaron captura, grabación con captura simultánea, Replay/recorte, importación de voz sintética, persistencia y reinicio de la app.

Con texto sintético de 2600 bytes y 500 reglas, el diccionario pasó de una mediana de 175,85 a 52,93 ms en cinco repeticiones. Es una medida del reemplazo de palabras, no de la latencia completa de Groq. La evaluación sintética ES/EN conservó el mismo error de palabras antes y después. No se redujeron modelo, resolución o calidad para mejorar esos números.

Replay consume recursos mientras está encendido. Su corrección de corte agrega un remux sin pérdida; no implica transcripción instantánea ni costo cero.

Existe un caso pendiente de retención cuando carpetas antiguas de grabaciones se redirigen fuera de la raíz esperada: la protección impide limpiarlas automáticamente. Esta versión conserva esos archivos y no relaja la validación de rutas. Las comprobaciones físicas, de múltiples monitores, suspensión y estabilidad de varias horas no se certifican con las pruebas locales realizadas.
