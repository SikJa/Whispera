# Whispera 0.2.25

## Espanol

Integra Whispera-K 0.2.23 (commit 32b265d) y publica la deteccion independiente
de novedades que hasta ahora estaba disponible solamente en la version local.

- Replay muestra Configurar y una flecha para abrir sus opciones.
- Configurar y activar guia la eleccion de carpeta y atajo. La grabacion comienza
  solo al pulsar Activar grabacion; Desactivar grabacion permite detenerla.
- Actualizaciones identifica novedades de K por cambios de codigo, no solamente
  por numeros de version. Las novedades ya integradas no se anuncian como pendientes.
- Los instaladores siguen viniendo exclusivamente de SikJa/Whispera, con nuestra
  firma. La deteccion de K no instala sus binarios ni sincroniza los repos automaticamente.
- Conserva el logo Cristal, el perfil unico, los atajos, el diccionario y la
  credencial Groq, junto con los arreglos propios de audio y portapapeles.

## English

Integrates Whispera-K 0.2.23 (commit 32b265d) and ships independent upstream release
detection, previously available only in the local build.

- Replay has an explicit configuration disclosure and guided folder/hotkey setup.
- Recording starts only after explicit activation, and can be disabled at any time.
- Upstream notices compare integrated source history instead of overlapping version numbers.
- Installable updates remain signed SikJa/Whispera releases. Upstream detection
  does not install K binaries or automatically synchronize the repositories.
- Preserves Cristal branding, the existing profile and Groq credential, shortcuts,
  dictionary protection, audio reliability and shareable clipboard exports.

## Validation

UI checks are silent and headless with mocked native IPC. Native tests use isolated
fixtures; no private audio is sent to Groq. Actual microphone capture, physical hotkeys,
receiver-specific paste/drop, and Windows reboot behavior are not certified by these checks.
