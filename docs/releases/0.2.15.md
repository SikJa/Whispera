# Whispera (K) 0.2.15

Actualizaciones desde la propia aplicación: nuevo apartado en Configuración con versión instalada, búsqueda, cambios y botón «Actualizar y reiniciar». Las novedades también aparecen en el menú de bandeja y en un aviso discreto en Configuración.

La app descarga desde este repositorio y verifica la firma antes de instalar. Conserva la carpeta de instalación, respalda la base de datos y vuelve a abrirse al terminar. No interrumpe dictados, transcripciones, capturas ni videos: bloquea la instalación hasta terminar el trabajo, incluso si comenzó mientras se descargaba.

Publicación automatizada para los cambios en main: genera una versión nueva, compila, firma, prueba y publica el instalador y su manifiesto. Una compilación o prueba fallida no se anuncia a los usuarios.

Usuarios de versiones anteriores: instalar esta versión una vez. Desde esta versión pueden actualizar dentro de Whispera.
